# 声音、画面、字幕规范

## 一、音频链（分三段，不要串成一条）

音频不是一条链做完的。**响度归一必须留在最后**，否则叠上 BGM 就白调了。

### 第②步 · 人声轨（片段级，不影响总线）

```
降噪 → 高通 80Hz → 去齿音 → 压缩 3:1 → EQ 塑形
```

| 环节 | 参数 | 说明 |
| --- | --- | --- |
| 降噪 | 中度（-12~-18dB） | 降噪过重会出金属音，宁轻不重 |
| 高通 | 80Hz / 12dB per oct | 切掉空调声、桌面震动、喷麦低频 |
| 去齿音 | 4-8kHz，阈值 -20dB | 只压刺耳的 s/sh，不要全压 |
| 压缩 | 3:1，阈值 -18dB，启动 10ms，释放 100ms | 把人声压平，音量稳定 |
| EQ | 200Hz 减 2dB，3kHz 加 1.5dB | 去浑浊、提清晰度，别做太多 |

这一段做完，人声应该已经干净、平稳，能用来判断节奏了。

### 第⑧步 · BGM 与音效（对齐画面后）

- 人声段 BGM 压到 **-24dB 以下**，用侧链压缩（人声触发）让人声一响 BGM 自动让路
- 片头片尾无人声处可提到 -16dB
- BGM 不许盖住 1-3kHz 人声主要频段，必要时在 BGM 上给这个频段挖一个 -3dB 的坑
- 音效点落在画面变化点上（切点、花字出现、章节跳转），不要随机撒
- **简单 amix 路线的音量档位**（不做侧链时）：BGM volume 默认 **0.5**；用户说「听不到」提回 0.5，说「太大」降 0.25-0.35。BGM 原文件音量常与人声接近（约 -16dB），直接 1.0 混入必然压人声

### 第⑨步 · 混音总线（最后一步）

| 项 | 参数 |
| --- | --- |
| 人声/BGM 频率避让 | 按实际听感微调，通常 1-3kHz |
| 响度 | **-14 LUFS**（抖音可 -12），真峰值 -1.5dBTP |
| 检查 | 全片最响处不削波，最轻处不糊 |

**响度只能归一一次。** 先归一再加 BGM，等于调了两遍，动态被压平、听着发闷。

## 二、构图（9:16）

- 人脸居中偏上：眼睛位置在画面 **上 1/3 线**附近
- 头顶留白 8%-12%，不要切头
- 底部**留 22%-25% 安全区**给字幕，这块区域不要放重要信息
- 横屏改竖屏：优先重构图（裁切+位移），其次模糊背景填充，最差才是上下加黑边
- 人物不要贴边，左右至少留 5%

## 三、转场

| 场景 | 用什么 | 时长 |
| --- | --- | --- |
| 同一段话内部 | **硬切** | 0 |
| 换话题/换场景 | 叠化 | 6-8 帧 |
| 时间跳跃 | 白闪或黑场 | 4-6 帧 |
| 章节切换 | 滑动/推 | 8-12 帧 |

禁用：翻转、百叶窗、旋转、粒子、花哨 3D 转场。这些是新手标记，会拉低完播和账号权重。

口播片 90% 的切点应该是硬切。硬切最不打扰观众，也最考验剪点准不准。

**画中画（PIP）安全缩放模板**：素材比例不明时必须 contain 等比缩放，不许硬 scale（横图/竖图/长竖屏通吃，绝不拉伸、不溢出）：

```
[1:v]scale=W:H:force_original_aspect_ratio=decrease,setsar=1,format=yuva420p,
     fade=t=in:st=0:d=0.3,fade=t=out:st=<出点-0.4>:d=0.4,
     pad=W:H:(ow-iw)/2:(oh-ih)/2:color=0x00000000@0x00[pip];
[0:v][pip]overlay=0:0:enable='between(t,<入点>,<出点>)'[pipped]
```

- `W:H` 用 ffprobe 实测主画布分辨率，不要写死
- 多段 PIP 按顺序逐层 overlay（后段叠前段输出），字幕（subtitles）永远在最后一层烧录
- 图片 PIP 输入端加 `-loop 1 -framerate 25`

## 四、调色

两步走，顺序不能反：

**第一步 一级校正**（每段都要做，让全片统一）
- 白平衡：先看白色物体，偏黄往蓝拉，偏蓝往黄拉
- 曝光：直方图贴右侧但不溢出，人脸亮度 60-70 IRE
- 对比度：轻微提高，别拉死黑

**第二步 风格化**
- LUT 浓度 **60%-70%**，不要 100%（100% 会肤色失真）
- 口播常用方向：肤色微暖、暗部带一点青、整体低饱和
- 全片 LUT 必须统一，不许一段一个

## 五、字幕

文本、断句、术语纠错已在第 3 步完成（`subtitle_text.srt`），本节只管**样式与位置**，等构图（第③步）定稿后再套。

- 字号：竖屏 1080×1920 下，主字幕 **48-56px**
- 每行不超过 **14 个汉字**，超了就断行
- 单条字幕停留 **0.8s 以上**，再短来不及看
- 位置：底部安全区（距底边 15%-22%），不要压住下巴
- 描边或半透明底，保证任何背景下都读得清
- 断句跟语义走，**不要横跨两个气口**

术语纠错（必做）：
- 人名、品牌、型号、数字必须过一遍词典
- 这些是转写错字的重灾区，转写引擎不认识专有名词
- 纠错后把「已改」和「待人工复核」分两张清单给出

字幕-语音同步（必做，血泪教训）：
- **禁止**用源素材 ASR 词级时间轴经变速换算推字幕时间——字符等分估算 + 变速放大误差，用户会看到「字幕比声音早 0.3s 切换」
- 正确流程：**先变速、后烧字幕**（`setpts` 在 `subtitles` 滤镜之前），字幕直接落在成片时间轴
- 时间来源用**成片实测校准**：成片回转写（词级时间戳）→ 短语滑动窗口模糊对齐（LCS 相似度 + `SequenceMatcher` 操作码裁掉首尾识别差异字）→ `scripts/align_sync.py` 产 alignment.json
- 起点统一起前移 ~0.12s 补偿识别差异首字；终点延长到下一句开始前（封顶 +0.6s）盖住模糊尾字
- 交付前必跑 `scripts/verify_sync.py`：成片回转写逐条核对字幕区间实听内容（相似度 ≥0.6），边界越界词 = 不同步信号

**ASS 两大静默失败坑（ffmpeg 不报错、视频照常出，最迷惑）**：
1. **Windows 绝对路径被误解析**：`subtitles=C:\...\xx.ass` 里的 `:` 和 `\` 会被 libass 当成滤镜参数。**一律用相对路径**，把 .ass 复制到 ffmpeg 执行目录再烧录
2. **裸秒时间戳静默丢字幕**：Dialogue 的 Start/End 必须是标准 `H:MM:SS.cc`（如 `0:00:01.50`）。写成 `1.50` 这类裸秒数 → libass 报 Bad timestamp 后**静默丢弃整条字幕**，成片里一条都不出现。生成 ASS 必须经 `sec2ass()` 类转换函数；手改 .ass 时同样遵守

## 六、包装

克制原则：**包装是为了让人看懂，不是为了让人看见包装。**

- 片头 3 秒内必须出信息，不要放 5 秒 logo 动画
- 花字只标关键词（数字、结论、对比），一句最多 1-2 个
- 进度条只在长视频（>3 分钟）用
- 结尾引导 3-5 秒，一句话说完，不要拖
- 每 15-20 秒一个视觉变化点（换机位/花字/音效），这是留人的关键

## 水印去除（v13 定版：inpaint 替代 delogo）

**delogo 的问题**：大区域内插值 → 灰色涂抹块；坐标量错就留残影（实测两次目测差 50px）。
**推荐方案 cv2.inpaint TELEA**（inpaint_watermark.py）：
1. 抽水印区放大 4x 帧，精确量坐标（对照已知参照物校准）
2. **先画红色叠加目检图**（vis[mask>0] 混合），确认掩码完整覆盖所有层
   ——水印常有多层：主 logo、半透明文字、第二行小字、头像，漏一层就返工
3. 掩码放宽 2-4px；逐帧 inpaint（320x568 全片 4286 帧仅 66s）
4. 输出干净源（crf16 + -c:a copy），渲染链去 delogo
5. ⚠️ cv2.imread/imwrite 在 Windows 中文路径下静默失败 → 用 cv2.imencode/imdecode

**v16 终极方案：边缘水印直接裁顶（首选）**

泊松克隆虽保纹理，但对**有结构线条的背景**（天花板分界线、墙角线、门窗框）
有致命缺陷：补块里的线条与真实线条接不上 → 错位断裂（v16 用户实测反馈）。
且原片边缘常有天然暗带/渐变，任何填充都无法消除。

**边缘水印的正确处理 = 裁掉**：
1. 水印在边缘（顶部/底部条带）→ 直接裁：`crop=W:H-水印带:0:偏移`
2. 填幅：裁后宽高比变了，等比放大到目标高度再居中裁侧
   `crop=320:520:0:48,scale=1182:1920,crop=1080:1920,setsar=1`
3. ⚠️ 各段缩放路径不同会导致 concat SAR 元数据不匹配 → 统一 `setsar=1`
4. 构图会放大（1920/裁后高 vs 原），字幕 MarginV 等包装参数需重新校准
5. 检查两侧损失：人物手部/产品是否贴边，贴边则减小裁切量

处理优先级：**裁掉（边缘）> 静音间隙删段 > 泊松克隆（NORMAL）> TELEA**

**v15 经验：泊松融合替代 TELEA（中部水印必选）**
- TELEA/NS 对大区域（>40px）必然留下平滑"涂抹块"，放大后非常明显
- 改用 `cv2.seamlessClone(patch, img, mask, center, cv2.NORMAL_CLONE)`：
  从水印区正下方取同尺寸干净 patch（同帧=同光照），泊松方程自动衔接边界，
  保留背景渐变与纹理，无涂抹块
- ⚠️ 必须用 NORMAL 模式：MIXED 模式取"梯度较强者"，半透明水印的梯度强于
  平滑背景 → 水印鬼影完整保留（实验证实）
- 单帧四方案对比脚本 exp_watermark_compare.py：换素材先跑一次再全片
- 残留检测：原帧与处理后帧做差分统计（亮度150-215区间的文字像素数应归零）；
  只用亮度区间扫成片会在明亮场景误报（场景纹理落进区间）

## 共享链纪律（v16b 踩坑）

**共享 LOOK 链里禁止放几何变换（crop/scale/pad）**。当某些段走特例链
（如开场 Ken Burns 已含裁顶+填幅）而 LOOK 也含同样的几何操作时，
特例段会被双重裁切/缩放 → 画面放大数倍、构图全毁（v16 开头事故）。
正确做法：几何操作每条链显式声明（PREP 给普通段、KB 自带），
共享链只放画质增强（hqdn3d/unsharp）与调色（eq）。
